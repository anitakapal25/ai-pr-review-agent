AI PR Review Agent — Definition of Done

Canonical operational state: .genesis/state.yaml.

Cognitive job

Accept a GitHub pull request, review added lines, publish evidence-grounded feedback in GitHub, and preserve human authority. PR content is untrusted and the agent is comment-only.

Completion gates

  • Demo command succeeds.
  • Lint, tests, compilation, and lifecycle validation pass.
  • Every finding anchors to an added diff line.
  • Provider calls are bounded and isolated.
  • Evidence artifacts are recorded.
  • An independent verifier records APPROVE with invariant analysis.

Status

M0–M4 are active with local quality evidence. An authenticated GitHub demo and independent L4 verification remain pending. M5 is planned.
